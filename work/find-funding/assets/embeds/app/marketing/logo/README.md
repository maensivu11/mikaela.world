# Find Funding logo

**The logo is the magnifying glass**: an ink ring and handle with a violet
(`#7668FF`) pixel at the centre, set beside "Find Funding" in Instrument Sans
600, letter-spacing −0.045em.

| File | Use |
|---|---|
| `find-funding-mark.svg` | the mark on light backgrounds |
| `find-funding-mark-on-dark.svg` | the mark on dark backgrounds |

In code, the homepage draws it with `Logo()` in
`frontend/src/components/home/marketing/Sections.tsx` (the same paths), next
to the words "Find Funding" as live text.

Not the logo: the violet double-F (`design_handoff_homepage/assets/ff-mark*.svg`,
`logo-lockup.svg`) and the old "findfunding.ai" wordmark
(`frontend/public/brand/wordmark-*.svg`, still used by the signed-in app).
